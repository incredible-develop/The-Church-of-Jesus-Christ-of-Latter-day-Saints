# Progress Bar

A bar that visually shows the user how far along a process they are

## Props

- `stepCount` - number, the maximum amount of steps/pages for the bar
- `currentStep` - number, current step/page set on the bar
- `theme` - string, color for the progress bar

### Common Props

- `background` - object, see the `background` component for details
- `layout` - object, see the `layout` component for details
