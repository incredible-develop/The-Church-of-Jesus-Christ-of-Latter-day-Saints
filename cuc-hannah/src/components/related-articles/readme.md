# Related Articles

Display articles in two ways (Editorial, Uniform) Tiles.

## Props

- `title` - string, Related Articles Title
- `tileStyle` - string, choose tile style
- `tiles` - object,
  - `heading` - string, Tile Heading
  - `primaryMeta` - string, Tile primary meta
  - `secondaryMeta` - string, Tile secondary meta
  - `content` - string, Tile content
  - `download` - boolean, download or not
  - `link` - object
    - `URL` - string, Tile URL
  - `image` - object, Tile image

### Common Props

- `background` - object, see the `background` component for details
- `layout` - object, see the `layout` component for details
