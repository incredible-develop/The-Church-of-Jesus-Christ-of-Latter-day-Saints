# Footer

The footer can import components to support language and a variety of other lists of links and components.

## Props

- `copyright` - string, ths sting after the copyright year
- `socialLinks` - array, an array of links
- `components` - object, houses components in arrays `a` and `b`
  - `langSel` - array, used to enter the language selector
  - `links1` - array, an array of components
  - `links2` - array, an array of components
- `churchLogoLink` - string, the reference for the church logo in a specified language
- `additionalComponents` - array, an array of components
- `meta` - object, an object that contains site-wide data.

### Common Props

- `background` - object, see the `background` component for details
- `layout` - object, see the `layout` component for details
