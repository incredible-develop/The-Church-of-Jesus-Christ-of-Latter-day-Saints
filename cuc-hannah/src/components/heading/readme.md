# Heading (Text Heading)

Displays heading on the webpage

## Props

- `text` - string, the text content for the heading
- `level` - string, the heading tag name, h1,h2,h3 etc. h5 is the default.
- `textColor` - string, the color of the heading
- `textJustification` - string, the horizontal alignment
- `styleOnly` - boolean, should the heading be styling only and not use the semantic heading level (use a `div` instead of `h#`)
- `internalPaddingMobile` - string, adds extra padding around the title for mobile
- `internalPaddingDesktop` - string, adds extra padding around the title

### Common Props

- `background` - object, see the `background` component for details
- `layout` - object, see the `layout` component for details
